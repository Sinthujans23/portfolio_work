# Decision: Data Storage: lowdb (JSON file) for project data and about content

- **Kind:** decision
- **Recorded:** 2026-09-02T23:05:44

## Decision
Data Storage: lowdb (JSON file) for project data and about content

## Reason
Provides simple file-based persistence suitable for a small portfolio, avoids needing a separate database service, and works with Node.js/Express in serverless functions.
